# Sazón — recetario personal para Android

Sazón es una app de Android para un solo usuario: apunta tus recetas de comidas, bebidas y postres, cocínalas paso a paso con temporizadores, haz la lista de la compra y guarda copias de seguridad (en el teléfono, en Google Drive o exportadas a un archivo). Funciona sin conexión y la interfaz está en español.
